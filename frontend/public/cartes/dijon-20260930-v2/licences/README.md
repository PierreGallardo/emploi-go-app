Les données du fond proviennent du snapshot [Protomaps du 30 septembre 2026](https://build.protomaps.com/20260930.pmtiles), version de source (`sourceVersion` du manifeste) 4.15.2. L'extrait couvre l'enveloppe de Dijon Métropole, de 4.866506, 47.189555 à 5.235783, 47.427760, aux niveaux 0 à 15.

Les ressources graphiques sont copiées du dépôt `protomaps/basemaps-assets` au commit `028c18f713baecad011301ff7a69acc39bcc2ae7`. Le manifeste contient les tailles et SHA-256 des fichiers distribués.

`dijon.pmtiles` est une base de données dérivée d'OpenStreetMap, mise à disposition sous ODbL 1.0. Les données Emploi Go restent dans une couche séparée et ne sont jamais intégrées à l'archive.

Les établissements affichés viennent de l'API Emploi Go, pas du fond OpenStreetMap. Un point ne désigne pas une offre d'emploi.
